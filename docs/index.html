سازنده Bucket Policy، CORS و Lifecycle

رابط وب فارسی (راست‌به‌چپ) برای تنظیم سیاست دسترسی، CORS و چرخهٔ عمر روی فضای ذخیره‌سازی ابری آروان (API سازگار با S3).

مخزن: github.com/RaminNietzsche/s3_policy_gen

توسعه با کمک هوش مصنوعی

این پروژه با مشارکت دستیارهای کدنویسی مبتنی بر هوش مصنوعی توسعه یافته است. ارسال Pull Requestهایی که با چنین ابزارهایی تهیه شده‌اند نیز مورد استقبال قرار می‌گیرد، مشروط بر رعایت امنیت، تست و کیفیت کد. جزئیات در CONTRIBUTING.md.

شروع سریع

git clone https://github.com/RaminNietzsche/s3_policy_gen.git
cd s3_policy_gen
make install
make serve

آدرس: http://localhost:8080

استقرار استاتیک

make assets
cp .deploy.env.example .deploy.env
make deploy

راهنمای کامل: DEPLOY.md

فونت‌های این صفحه: وزیرمتن برای متن فارسی و JetBrains Mono برای کد — همان فونت‌های رابط کاربری اپلیکیشن.
