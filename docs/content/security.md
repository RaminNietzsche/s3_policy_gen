# امنیت

اصول امنیتی **s3_policy_gen** و توصیه‌های استفاده در محیط تولید.

---

## کلیدهای دسترسی (Access / Secret)

| محیط | رفتار |
|------|--------|
| **localhost + server.py** | کلیدها فقط در حافظهٔ همان تب مرورگر |
| **سایت استاتیک عمومی** | ورود کلید **غیرفعال** است |
| **localStorage** | Secret ذخیره نمی‌شود؛ اختیاری: Access Key + کلاستر تا بستن تب |

هرگز کلید production را روی URL عمومی (مثلاً bucket استاتیک) وارد نکنید.

---

## فایل `.deploy.env`

- برای `make deploy` لوکال است.
- در `.gitignore` قرار دارد — **commit نشود**.
- برای `make deploy-quick` هر سه مقدار `S3_*` لازم است.

---

## پروکسی `/s3-proxy`

`server.py` درخواست‌های امضاشده را به endpoint آروان فوروارد می‌کند.

- فقط برای توسعهٔ لوکال طراحی شده است.
- بدون آگاهی `server.py` را به اینترنت expose نکنید.

---

## مسئولیت پیکربندی

خروجی Policy / CORS / Lifecycle می‌تواند:

- دسترسی را به‌طور کامل ببندد،
- یا داده را برای همه قابل خواندن کند.

**قبل از اعمال روی bucket تولید، خروجی را بازبینی کنید.**

از الگوهای `Principal: "*"` و دسترسی نوشتن عمومی فقط در صورت نیاز واقعی استفاده کنید.

---

## گزارش آسیب‌پذیری

جزئیات exploit یا کلید واقعی را در Issue عمومی منتشر نکنید. از Security Advisory خصوصی GitHub استفاده کنید.
