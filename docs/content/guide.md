# راهنمای استفاده

راهنمای گام‌به‌گام رابط کاربری **s3_policy_gen** برای فضای ذخیره‌سازی ابری آروان.

> مستندات: [policygen.ceph-s3.ir](https://policygen.ceph-s3.ir/)  
> برای اتصال به bucket و اعمال مستقیم: `make serve` و `http://localhost:8080`

---

## نمای کلی صفحه

1. **سربرگ** — عنوان، پوستهٔ روشن/تیره
2. **اتصال اختیاری** — کلید S3 (فقط localhost + `server.py`)
3. **نام bucket** — مشترک بین هر سه تب
4. **تب‌ها** — Policy · CORS · Lifecycle
5. **خروجی** — JSON یا XML، کپی، دانلود، اعمال

---

## نام bucket و Account ID

### Bucket

نام bucket را در فیلد بالای صفحه وارد کنید یا پس از اتصال لوکال از فهرست انتخاب کنید. این نام در هر سه تب یکسان است.

### Account ID (تب Policy)

شناسهٔ مالک bucket در آروان است. با پر کردن آن، یک قانون **دسترسی کامل مالک** به‌صورت خودکار به Policy اضافه می‌شود تا حساب شما از قفل شدن accidental جلوگیری شود.

---

## تب Bucket Policy

### الگوهای آماده

دکمه‌های الگو (مثلاً خواندن عمومی، آپلود محدود) قالب را در فرم قرار می‌دهند؛ پس از بازبینی **افزودن قانون** را بزنید.

### افزودن قانون دستی

| فیلد | توضیح |
|------|--------|
| نوع دسترسی | Allow (مجاز) یا Deny (مسدود) |
| برای چه کسی | ARN کاربر، `*` (همه)، یا کاربران دارای کلید |
| روی چه بخشی | فقط فایل‌ها، فقط bucket، یا bucket و همهٔ فایل‌ها |
| کارهای مجاز | خواندن، نوشتن، لیست، پاک‌کردن و … |
| شرط | اختیاری — IP، پیشوند مسیر و … |

### ترتیب قوانین

قوانین از **بالا به پایین** در JSON نهایی قرار می‌گیرند. قوانین **Deny** معمولاً باید قبل از Allowهای بازتر باشند.

### خروجی Policy

خروجی JSON در جعبهٔ پایین نمایش داده می‌شود. با **کپی** یا **دانلود** (`bucket-policy.json`) ذخیره کنید.

> در نسخهٔ استاتیک عمومی فقط ساخت و کپی ممکن است. **اعمال مستقیم** فقط پس از `make serve` و اتصال با کلید فعال است.

---

## تب CORS

CORS به **مرورگر** می‌گوید از کدام Origin می‌تواند به bucket درخواست فرستاد؛ جایگزین Policy نیست و هر دو لازم‌اند.

### نکات مهم

- قوانین **از بالا به پایین** ارزیابی می‌شوند؛ اولین تطابق برنده است.
- اگر `*` را **بالا** بگذارید، قوانین دقیق‌تر پایین اغلب اجرا نمی‌شوند.
- برای آپلود از مرورگر معمولاً `GET`، `PUT` و `OPTIONS` لازم است (preflight).

### فیلدهای هر قانون

| فیلد | توضیح |
|------|--------|
| سایت‌های مجاز (Origin) | هر خط یک آدرس، مثلاً `https://app.example.com` یا `*` |
| متدهای مجاز | `GET`، `PUT`، `HEAD` و … |
| هدرهای مجاز | اغلب `*` برای سادگی |
| هدرهای پاسخ | برای دیدن `ETag` در JS مثلاً `ETag` |
| مدت کش preflight | ثانیه — کاهش درخواست OPTIONS تکراری |

خروجی: فایل XML (`cors-configuration.xml`).

---

## تب Lifecycle

قوانین نگهداشت خودکار اشیاء (حذف بعد از N روز، پاک‌سازی multipart ناقص).

### محدودیت‌های سرویس

- هر قانون باید شامل **حداقل یک** از «حذف بعد از N روز» یا «پاک‌سازی آپلود ناقص» باشد.
- **انتقال به کلاس ذخیره‌سازی دیگر** در این ابزار غیرفعال است (پشتیبانی محدود در برخی کلاسترها).

### فیلدهای هر قانون

| فیلد | توضیح |
|------|--------|
| شناسهٔ قانون | نام یکتا در XML |
| وضعیت | Enabled / Disabled |
| مسیر پوشه | اختیاری — محدود به prefix |
| حذف بعد از (روز) | حذف اشیاء قدیمی‌تر از N روز |
| پاک‌سازی multipart | حذف آپلودهای ناقص قدیمی |

خروجی: `lifecycle-configuration.xml`.

## اتصال به فضای ذخیره‌سازی (لوکال)

### چه زمانی فعال است؟

فقط وقتی:

- صفحه روی `http://localhost` باز باشد، **و**
- `python3 server.py` (یا `make serve`) در حال اجرا باشد.

روی هر URL استاتیک عمومی (بدون `server.py` لوکال) فیلدهای کلید **غیرفعال** هستند.

### مراحل اتصال

1. بخش **اتصال اختیاری** را باز کنید.
2. کلاستر / Endpoint را انتخاب کنید.
3. Access Key و Secret Key را وارد کنید.
4. **اتصال و دریافت bucketها** را بزنید.
5. bucket را از فهرست یا دستی انتخاب کنید.

پس از اتصال، تنظیمات فعلی bucket (در صورت وجود) **بارگذاری** می‌شود.

### امنیت کلید

- Secret در `localStorage` ذخیره **نمی‌شود**.
- با بستن تب یا **قطع اتصال**، Secret از حافظه پاک می‌شود.
- فقط Access Key و کلاستر را می‌توانید تا بستن تب به‌خاطر بسپارید.

## اعمال و حذف روی آروان

### اعمال مستقیم

1. در محیط لوکال متصل باشید.
2. خروجی تب مورد نظر را بسازید.
3. در بخش **اعمال روی bucket** گزینه **اعمال مستقیم روی آروان** را انتخاب کنید.
4. راهنما و **تأیید مسئولیت** را بخوانید و تأیید کنید.

درخواست از مرورگر به پروکسی `server.py` و سپس به endpoint آروان ارسال می‌شود.

### حذف تنظیم از bucket

دکمه **حذف از آروان** فقط وقتی نمایش داده می‌شود که:

- همان تنظیم (Policy / CORS / Lifecycle) از bucket **بارگذاری شده** باشد، و
- اتصال لوکال برقرار باشد.

---

## اعمال با CLI (بدون اتصال در UI)

در بخش اعمال، کلاینت‌های **AWS CLI**، **s3cmd**، **rclone** و … راهنمای دستور و فایل موقت را نشان می‌دهند.

---

## محدودیت‌های شناخته‌شده

- سیاست IAM سطح حساب (نقش/گروه) — پشتیبانی محدود
- جایگزینی متغیر در Policy — پشتیبانی نمی‌شود
- CORS و Lifecycle فقط روی خود bucket تنظیم می‌شوند

لیست کامل در پنل **نکات فضای ذخیره‌سازی ابری** داخل ابزار.

## عیب‌یابی

| مشکل | راه‌حل |
|------|--------|
| صفحه بدون استایل | در deploy استاتیک `make fix-mime`؛ در مرورگر Hard Refresh |
| `App script failed to load` | `make serve` را ری‌استارت کنید؛ آدرس `localhost:8080` |
| اتصال خطا می‌دهد | endpoint و کلید را بررسی کنید؛ دسترسی‌های S3 روی bucket |
| اعمال مستقیم غیرفعال | فقط localhost + `server.py` |
